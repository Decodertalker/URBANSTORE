1. Descargar la plantilla

Hojas GENERAL, entrada y SALIDA. Para cargar productos llena solo la hoja entrada. El ID y el código se crean solos.

Descargar plantilla

2. Importar la hoja “entrada”

Cada fila suma su cantidad a la existencia. Si el producto no existe se crea, y si la categoría no existe también. No subas el mismo archivo dos veces: la cantidad se sumaría de nuevo.

3. Descargar la base de datos actualizada

Un solo archivo con tres hojas: GENERAL (inventario actual), entrada y SALIDA, con las mismas columnas de la plantilla y el usuario que registró cada movimiento.
